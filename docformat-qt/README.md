# DocFormat Pro (Qt)

公文格式自动排版工具（GB/T 9704-2012），PyQt5 桌面应用。
支持 **Windows** 与 **麒麟 / 统信 UOS 等国产系统**（含飞腾/鲲鹏 ARM 架构）。

排版引擎复用自 [docformat-gui](https://github.com/KaguraNanaga/docformat-gui)（MIT），本项目在其之上提供：
Qt 原生文件拖拽（麒麟 ARM 可用）、Linux 下 .doc/.wps 输入（LibreOffice 转换链）、
信创内网系统源部署、可视化模板编辑与持久化、AI 粘贴生成公文、四套界面主题。

## v3.0 界面与易用性

- **首次启动引导**：三个任务入口（排版文件 / 起草公文 / 历史件做模板）直达对应页面
- **内置使用说明**：F1 或侧边栏「使用说明」，含页面导览、模式说明、快捷键、常见问题
- **键盘快捷键**：Ctrl+1~7 切页、Ctrl+O 选文件、Ctrl+回车 开始处理
- **对比预览左右同步滚动**；预览窗口大小与分割位置自动记忆
- **记住使用习惯**：输出后缀、修订模式、上次处理模式重启后保持
- **全窗口拖拽**：文件拖到任何页面都自动进入格式处理
- **处理模式卡片化**（2×2 点选）；侧边栏导航配主题色图标（程序绘制，信创系统无字体依赖）
- **错误提示白话化**：文件损坏/被占用/磁盘满等给出可操作的中文提示
- **新版本提醒**：启动时后台检查 Releases，有新版在状态栏提示（离线环境静默跳过）

## 功能

- **智能一键处理**：标点修复 → 排版规范（页边距/字体/字号/缩进/行距/页码/表格）→ 样式清洗
- **排版前后对比预览**：左右分栏显示原文与模拟排版效果（含每段识别类型标注），确认无误后才真正写文件；
  **点击段落类型标签可手动指定**该段是标题/正文/附件等，手动调整在实际排版时生效；
  预览支持 .docx / .txt / .md，.doc/.wps 自动转换后预览
- **公文合规检查**：只检查不修改，逐段按识别出的类型对照预设核对（字体/字号/加粗/对齐/缩进/行距/段距）
  与页面级项（边距/纸张/网格/页码）；勾选认可的偏差才修正，其余保持原样
- **标点修复**：仅规范中英文标点，不动版式；英文撇号（it's）、跨段引号、英文单词间空格均受保护
- **发文字号**：自动识别"××发〔2026〕12号"并按仿宋居中排版，字体字号可在模板中调整
- **修订模式输出**：可选把所有改动写成 Word 修订（审阅中可见、可逐条接受/拒绝）
- **AI 粘贴生成**：粘贴 AI 写的文本/Markdown，自动清洗标记并产出规范公文 docx
- **密级标识**：自动识别文首"秘密★1年 / 机密★3年 / 绝密"等定密行（仅文档前 3 个非空段、整行匹配才认定），按三号黑体顶格排版，可在模板中自定义
- **密级标注检查**（合规检查里的独立一组，默认开）：查文件**自己露出来的破绽**，不做"看着像涉密"的猜测——
  · 有份号却没有密级（GB/T 9704：份号只标在涉密公文上）；
  · 正文写着"注意保密""不得公开""本件为机密件"，版头却没有密级行；
  · 有密级但缺保密期限、分隔符不是「★」、期限用中文数字、密级词写错（机秘/绝秘）；
  · 密级位置不对（版头顺序应为 份号 → 密级 → 紧急程度；或密级跑到正文里去了）。
  可一键补标，但**密级和保密期限必须由你在界面上选定**——标错密级比不标更麻烦，
  软件只负责把选定的内容排到版头正确位置并按预设排版
- **识别规则可自定义**：密级/发文字号/各级标题/附件/署名/日期/结束语/主送机关共 11 类要素的识别规则
  均可在"预设方案 → 识别规则"中修改。常用方案（如法律条文"第一条"）直接下拉选择，无需写正则；
  进阶用户可选"自定义"填正则，并用**实时测试框**粘贴一行文字立即验证识别结果，非法正则自动回退
- **模板系统**（内置模板名称可重命名，参数只读，复制后可全改）：内置四套模板，默认为**公文格式（图解版·22行28字）**——A4，上3.8/下3.3/左右2.8cm
  边距，方正小标宋_GBK 二号标题、方正黑体/楷体/仿宋_GBK 三号加粗各级标题与正文，行距固定 28 磅，
  文档网格每页 22 行 × 每行 28 字，页码四号半角宋体，落款按"成文日期右空 2 字、
  署名与日期首字错 2 字"自动对位；另含通用公文（GB/T 9704）/学术/法律三套；
  自定义模板可视化编辑、即时保存、JSON 导入导出
- **对齐方式**：左对齐 / 居中 / 右对齐 / **两端对齐** / **分散对齐**，每类段落各自可设；
  内置的"常用排版"模板正文默认两端对齐
- **套打（打在预印红头纸上）**：预印内容以白字占位——占准位置但不显影，
  黑字才是打印机要印的。整张纸按 A4 比例画在画布上，黑字可直接拖着挪；
  每栏的落点可按尺子量的厘米数逐一填写，定位用 Word 制表位（与字体无关，实测误差 <0.01cm）；
  可拿一张空白套头纸的扫描件**自动对位**；支持从 Excel/CSV **批量套打**、套头库自动认出配套的红头纸；
  **直接打印**（按 100% 实际大小送打印机，不做任何缩放），并可先打一张
  **对位测试页**到普通白纸上——每栏标着它会印到距纸左边多少厘米，
  和真实预印纸对光一叠就知道差多少，不必拿预印纸试打
- **套打模板可视化编辑**：点中纸上任意一个字就地改——内容、中西文字体、字号、
  预印/填写位、整段字的宽度（靠字距收放），位置可拖可填，支持撤销重做；
  存回 docx 时替你守住制表位、精确行距、白字这些一改就废的地方
- **公文用语检查**（独立模式，与版式检查分开）：数字用法、结构用语、文种搭配等 15 条规则，
  内置 352 条高频错词（易误伤的带防撞护栏）；结果先列清单并逐词显示「原文 → 改后」，
  认可哪条才改哪条，改动一律写成 Word 修订留痕
- **表格**：边框、列宽、行高标准化；可选**三线表**（只留顶线、栏目线、底线，不画竖线）、
  **跨页重复表头**（续表自动带上栏目名，表头几行都重复）、整行不被页边切断
- **附件另面编排**：附件标识行自动另起一页（GB/T 9704），可在预设里关掉
- **输入格式**：.docx 直接处理；.doc/.wps 自动经 WPS/Word/LibreOffice 转换；
  .txt/.md 纯文本与 Markdown 按 AI 粘贴规则清洗后排版（自动识别 UTF-8/GBK 编码）
- **字体检查**：开始处理前自动检测本机是否安装预设所需字体（如方正仿宋_GBK），缺失时明确提示
- **格式清洗**：原文档的行距、首行缩进（含空格/Tab 顶格）、段前段后、对齐、颜色下划线等
  全部清除并按模板重设，不受原格式干扰
- **批量处理**：多文件/整个文件夹拖入，逐文件状态标记（✓/✗）与日志，完成后一键打开输出位置；
  输出在原文件旁加后缀，不覆盖原文件，重名时自动追加序号；批量转换 .doc/.wps 时 Office/WPS 实例整批复用
- **高分屏适配**：125% / 150% 等非整数缩放按真实比例渲染（PassThrough）

## Windows 使用

```bat
pip install -r requirements.txt
双击 启动.bat        （或 python main.py）
```

打包独立 exe（免 Python 环境分发）：

```bat
pip install pyinstaller
packaging\build_windows.bat     → dist\DocFormatPro.exe
```

.doc/.wps 输入依赖本机 WPS 或 Microsoft Word（自动检测，WPS 优先）。

## 麒麟 / UOS 使用

**方式一（最简单）**：从 [Releases 页面](../../releases) 下载对应架构的
`DocFormatPro-*-linux-x86_64.tar.gz`（Intel/AMD/兆芯/海光）或
`DocFormatPro-*-linux-arm64.tar.gz`（飞腾/鲲鹏），解压后运行：

```bash
tar xzf DocFormatPro-*-linux-*.tar.gz && cd DocFormatPro && ./DocFormatPro
```

二进制在 glibc 2.28 环境构建，兼容麒麟 V10、统信 UOS 20 及更新系统。
.doc/.wps 输入需另装 LibreOffice：`sudo apt install libreoffice-writer`。

**方式二（内网/二进制不可用时，源码部署）**

```bash
bash packaging/install_kylin.sh
```

脚本会通过**系统源** `apt install python3-pyqt5 python3-docx`（内网可用，无 glibc 兼容问题），
并安装桌面图标，之后双击图标即可启动。

- .doc/.wps 输入需要 LibreOffice：`sudo apt install libreoffice-writer`（仅处理 .docx 则无需安装）
- 二进制打包（可选）：在目标架构机器上执行 `bash packaging/build_linux.sh`

## 目录结构

```
main.py            入口
app/               Qt 界面（主窗口/七个页面/拖拽控件/主题/模板管理/处理线程）
scripts/           排版引擎（来自 docformat-gui，MIT）
packaging/         Windows/Linux 打包与麒麟安装脚本
smoke_test.py      引擎冒烟测试
gui_test.py        GUI 自动化测试（offscreen 运行）
```

用户模板存储位置：Windows `%APPDATA%\DocFormatPro\templates.json`，Linux `~/.config/DocFormatPro/templates.json`。
